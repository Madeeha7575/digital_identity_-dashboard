# Digital Identity Dashboard

## 📌 Overview
Digital Identity Dashboard is a software‑only AI web application that enables organizers and professionals to analyze a consented image and limited context to discover, correlate, and verify publicly available information about an individual.  

This project focuses on **identity correlation, verification, and visualization** — providing a secure, evidence‑based dashboard for digital identity insights.

---

## 🚀 Features

- **User Authentication**  
  Secure log/sign‑in flow with personalized dashboard redirect.

- **Input System**  
  Requires at least two inputs (image, name, or URL) for analysis.

- **Profile Display**  
  - Shows retrieved or provided image.  
  - Displays contextual name.  

- **Socials Integration**  
  - Icons for Instagram, X/Twitter, LinkedIn, GitHub, YouTube.  
  - Reveals available accounts with URLs.  
  - Shows account status (active/inactive).  

- **Achievements Tracking**  
  - Technical → hackathons, publications, patents.  
  - Entertainment → concerts, albums, films, theatre.  
  - Business → brands, investments.  

- **Workspace Timeline**  
  - Past/current work experiences.  
  - Timeline view of active/inactive roles.  
  - Relationship graph of affiliations.  

- **History Tab**  
  Stores previously searched individuals for quick access.

- **Verification Layer**  
  - Evidence (source URLs, screenshots).  
  - Confidence scores attached to each result.  
  - Flags uncertain or conflicting information.  

---

## 🛠 Tech Stack

- **Frontend**: React / Next.js  
- **Backend**: Node.js / Express  
- **Database**: MongoDB or PostgreSQL  
- **AI Layer**: Identity correlation APIs & ML models  
- **Security**: OAuth2, JWT authentication, encrypted storage  

---

## 🎯 Use Cases

- Event organizers verifying participant achievements.  
- Recruiters cross‑checking candidate portfolios.  
- Researchers analyzing public digital footprints.
